# Screenshots

This folder is reserved for sanitized screenshots captured from the lab environment.

Before uploading screenshots, remove or blur:

- Real customer names
- Real IP addresses
- Public IP addresses not reserved for documentation
- Usernames
- Passwords
- Firewall serial numbers
- License details
- Hostnames
- MAC addresses
- Any internal customer details

Suggested screenshots:

- `topology.png`
- `subnetting-plan.png`
- `security-zones.png`
- `nat-policy.png`
- `security-policy.png`
- `globalprotect.png`
- `ipsec-vpn.png`
- `traffic-logs.png`
