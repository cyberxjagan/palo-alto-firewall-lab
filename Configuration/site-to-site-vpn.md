# Site-to-Site IPsec VPN

## Purpose

A Site-to-Site IPsec VPN was configured to simulate secure connectivity between Head Office and Branch Office networks.

## Configuration Scope

- IKE Gateway
- IPsec Tunnel
- Tunnel Interface
- Routing for remote network
- Security policies for VPN traffic

## Validation

- Verified tunnel status
- Tested Head Office to Branch Office reachability
- Verified route and policy matching
- Reviewed VPN and traffic logs
