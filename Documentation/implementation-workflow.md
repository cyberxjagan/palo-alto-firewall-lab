# Implementation Workflow

1. Reviewed project requirements.
2. Planned the IPv4 subnetting design for four departments.
3. Created the logical network topology.
4. Configured Palo Alto Layer 3 interfaces.
5. Assigned interfaces to security zones.
6. Configured virtual router and default route.
7. Created department-based security policies.
8. Configured Source NAT for internal Internet access.
9. Configured Destination NAT for DMZ publishing.
10. Integrated LDAP / Active Directory authentication.
11. Applied URL Filtering profile.
12. Configured GlobalProtect VPN.
13. Configured Site-to-Site IPsec VPN.
14. Validated routing, NAT, policy and VPN connectivity.
15. Documented implementation and testing steps.
